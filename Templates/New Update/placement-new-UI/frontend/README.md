# VrikshaHire client

## Run

Start the API from the project root with `node server.js`, then start this client:

```sh
npm install
npm run dev
```

The client uses the API at `http://localhost:5000`.

## Screens

- Student login and signup
- Open jobs and notices
- Student application history and applied-job state
- Admin sign-in and a dashboard of placement totals and recent applicants

Admin credentials are configured in the root `.env` file as `ADMIN_EMAIL` and `ADMIN_PASSWORD`. Do not commit that file.
